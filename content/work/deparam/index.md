A single-page URL deparameterizer. Paste any URL and the query string is instantly split into a color-coded key/value table. Useful for debugging analytics payloads, signed URLs, or any long query string you need to read at a glance.

Built with vanilla HTML, CSS, and ES5 JavaScript with no dependencies and no build step. Features a Dracula/synthwave theme with glow effects, a CRT scanline animation on each parse, and sortable columns.
