A coding agent plugin that stops your computer from sleeping while a coding agent works. It prevents sleep only while the agent is busy. When the agent goes idle, your usual sleep settings take over again.

Supports Claude Code, OpenCode, and Codex, and macOS, Linux, and Windows.
